  • Classical Concert Map

    Upcoming classical concerts worldwide, and an archive of past performances, on a map. Search by composer, piece, orchestra, city, and time period.

  • NC BBQ Map github

    Old-school North Carolina barbecue restaurants on a map: pork, salt, hardwood coals, chopped.

  • Ireland Travel Map

    A trip-planning map of Ireland: historic sites with parking and walk-in notes, geology and viewpoints, GAA grounds and fixtures, where locals eat, pubs with a trad session, and the railways.

  • GAA Map github

    Every inter-county hurling and football fixture gaa.ie lists, on a map of Ireland, filterable by sport, level, competition, team, and date.

  • Tennis Map github

    Every professional tennis tournament of the season on a map, from the Grand Slams down to the ITF tour, filterable by tour, level, surface, and date.

  • Libretto Finder github

    Where to find an opera libretto with the original and an English translation side by side, listed by composer and opera.

  • Insightful Essays github

    A short list of essays, with a paragraph on why each one is there. Atom feed.

  • Headline Search github

    Every news headline GDELT has recorded since October 2019, searchable by word or substring, with a date range and a source filter.
